# FantaPilot GitHub Pages mini-site

Contenuto pronto per un mini-sito statico da pubblicare su GitHub Pages.

## File inclusi

- `index.html` - home essenziale del progetto
- `privacy-policy.html` - pagina da usare nel Play Store
- `support.html` - pagina supporto/contatti

## Placeholder da completare prima della pubblicazione

Nei file HTML sono presenti ancora alcuni placeholder:

- `[TO COMPLETE]` per `Effective date`
- `[TO COMPLETE]` per `Publisher / Developer name`
- `[TO COMPLETE]` per `Support email`

## Pubblicazione su GitHub Pages

1. carica questi file nella root del repository del mini-sito
2. vai in `Settings > Pages`
3. imposta `Deploy from a branch`
4. scegli branch `main` e cartella `/ (root)`
5. attendi la generazione dell'URL pubblico

## Estensioni facoltative

- aggiungere `downloads/` per ospitare la Lista Giocatori o altri file pubblici
- aggiungere una feature graphic o screenshot ottimizzati per il sito
- aggiungere un file `404.html` o una pagina FAQ
